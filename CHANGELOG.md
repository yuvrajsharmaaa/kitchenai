# Changelog

All notable changes to this project will be documented in this file.

The format is based on Keep a Changelog, and this project follows Semantic Versioning.

## [0.1.0] - 2026-05-28
### Added
- FastAPI backend with segmentation and inpainting endpoints.
- SegFormer segmentation pipeline with per-class masks and overlays.
- ControlNet inpainting pipeline with mask and Canny control.
- SUN RGB-D conversion scripts for training experiments.
- Beginner-friendly documentation and contribution guidelines.

### Notes
- Large model weights and datasets are intentionally ignored by .gitignore.
